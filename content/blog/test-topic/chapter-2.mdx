# React Server Components (RSC)

Server Components allow you to write UI that can be rendered and optionally cached on the server.

In Next.js, the App Router is built on top of Server Components, enabling better performance and developer experience.

## Benefits of RSC:
- Zero bundle size impact
- Access to backend resources directly
- Improved SEO
